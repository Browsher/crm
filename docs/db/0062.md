# 0062 · Excluir CNPJs já entregues pelo Banco

A aplicação passa a reservar novas pesquisas com `busca_empresa_reservar_casa_com_exclusoes`. A função reaproveita as verificações da reserva anterior. Só uma reserva nova bem-sucedida retorna os CNPJs já entregues pelo Banco, identificados pela origem inicial do vínculo. A busca recebe a lista global, sem responsáveis ou contatos.

Os CNPJs ficam no servidor e seguem no campo `excluir.cnpj` da requisição à Casa dos Dados. A função anterior continua disponível para a versão publicada durante a transição. Aplicar a migração antes de publicar a versão que usa a nova função.
