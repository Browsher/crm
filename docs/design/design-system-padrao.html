Referência visual 0.1 para avaliação. As ações e os dados deste arquivo são demonstrações locais.

Sobre esta referência

As cores e a fonte seguem a base visual auditada do CRM. A composição de estados vazios incorpora a preferência por Card compartilhado e ação padronizada no rodapé. Os exemplos unificam medidas e estados para avaliação antes da adoção.

Arquivo independente em HTML, CSS e JavaScript, sem recursos externos. Reproduz a linguagem visual dos componentes shadcn/ui; não contém os componentes React do aplicativo. As abas de produção têm referência SmoothUI, encontrada no catálogo 21st. Ícones Lucide incorporados ao arquivo sob licença ISC.

O CRM, suas consultas, os controles de acesso e os fluxos operacionais não são alterados por esta prévia.
